# PetLocal

Sistema web para cadastro de pets e busca de pets desaparecidos ou encontrados, conectando tutores e pessoas que encontram animais.

Demo: https://projeto-pet-local.vercel.app/#/home

## Funcionalidades
- Cadastro de pets
- Registro de pets desaparecidos
- Registro de pets encontrados
- Busca e consulta de animais

## Tecnologias
- React
- TypeScript
- HTML e CSS
- Deploy na Vercel

## Contexto
Projeto acadêmico do curso de Engenharia de Software (Fateb), com foco em arquitetura de software e experiência do usuário (IHC).
